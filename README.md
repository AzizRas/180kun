# LEVEL 180

180-дневный сезон изменения тела для Узбекистана: ИИ-тренер, сквад из шести
человек, лига и офлайн-встречи. Русский и узбекский.

**PHP 8 + SQLite + чистый JS. Без сборки, без npm, без сервера БД.**
Заливаете папку на хостинг — работает.

---

## Установка за 5 минут

1. Залейте содержимое папки в корень сайта (`public_html` или `www`).
2. Дайте папке `storage/` права на запись (755, обычно уже так).
3. Откройте `config.php` и поменяйте:
   - `app.url` — адрес сайта;
   - `app.debug` — поставьте `false` перед запуском;
   - `admin.password` — пароль админки;
   - `admin.email` — этот аккаунт станет админом.
4. Откройте `https://вашсайт/health` — все строки должны быть зелёными.
5. Зарегистрируйтесь на `https://вашсайт/`.

Требования к хостингу: PHP 8.0+, расширения `pdo_sqlite` и `mbstring`,
`curl` — только если подключаете ИИ. MySQL, Node, Docker, Composer не нужны.

## Локальный запуск

```bash
php tools/migrate.php
php -S localhost:8000 index.php
# затем http://localhost:8000/health
```

## Управление составом продукта

Файл `modules.php` — главный рычаг. Убрали строку — модуль исчез из
приложения, остальное продолжает работать. Проверить последствия:
откройте `/health`, раздел «Контракты» покажет, какие возможности
перешли на заглушки.

## Команды

```bash
php tools/smoke.php              все проверки
php tools/migrate.php            применить миграции
php tools/make-module.php Squad  скелет нового модуля
```

## Резервная копия

Вся база — один файл `storage/db/level180.sqlite`. Скачивайте раз в неделю.
