# CLAUDE.md — инструкция для Claude по этому проекту

Этот файл читается автоматически в начале каждой сессии. Он существует
потому, что между сессиями память не сохраняется. Всё, что нужно знать,
чтобы продолжить работу, — здесь.

## Порядок действий в начале каждой сессии

1. Прочитать **STATE.md** — где мы остановились и что делаем следующим.
2. Заглянуть в **ROADMAP.md** — какой срез в работе.
3. Свериться с **DECISIONS.md**, если задача касается продуктовой логики.
4. Работать. В конце сессии **обязательно обновить STATE.md** — это не
   формальность, без этого следующая сессия начнётся вслепую.

## Что это за продукт

LEVEL 180 — 180-дневный сезон изменения тела для Узбекистана: ИИ-тренер,
сквад из шести человек, лига, офлайн-встречи в Ташкенте. Интерфейс на
русском и узбекском. Аудитория 23–36 лет.

Главный принцип продукта, из которого следует всё остальное:
**проигрыш не в падении, а в том, что перестал возвращаться.**
Поэтому главная метрика — Return Rate, а не DAU.

Полное обоснование решений — в досье (артефакт «LEVEL 180 — Досье решений»),
краткая выжимка решений Р-01…Р-22 — в DECISIONS.md.

## Стек и жёсткие ограничения

- **PHP 8.0+, SQLite, чистый JS.** Ничего больше.
- **Запрещено:** Composer, npm, Docker, сборщики, фреймворки, внешние
  зависимости. Цель — папку заливают на shared-хостинг за $2–3 и она работает.
- Автозагрузка своя, в `app/Kernel.php`. Composer не появится.
- Таймзона Asia/Tashkent. Все метки времени в базе — UTC в формате ISO 8601.
- Комментарии и строки интерфейса — на русском, имена классов и полей — на английском.

## Архитектура в двух абзацах

Модульный монолит с дисциплиной микросервисов. Ядро (`app/`) не знает ни об
одном модуле. Каждый модуль в `modules/<Name>/` самодостаточен: свои таблицы
с префиксом, свои миграции, свои маршруты, свои переводы.

Модули **не вызывают друг друга напрямую**. Только два способа связи:
события (`$kernel->events`) и контракты из `app/Contracts/`. У каждого
контракта есть заглушка в `Nulls.php`, поэтому выключение модуля в
`modules.php` не роняет приложение — оно теряет возможность, но работает.

## Правила, которые нельзя нарушать

1. **Модуль читает и пишет только свои таблицы.** Никаких JOIN между
   таблицами разных модулей. Чужие данные — через контракт или событие.
2. **Ядро не знает имён модулей.** Если в `app/` появилось слово `squad`
   или `checkin` — это ошибка проектирования.
3. **Домен не знает про HTTP.** Доменные методы возвращают `Result`,
   а не `Response`. Иначе их нельзя переиспользовать из Telegram-бота и тестов.
4. **Новая возможность = новый модуль**, а не новый `if` в существующем.
   Скелет создаётся командой `php tools/make-module.php ИмяМодуля`.
5. **Каждый модуль объявляет в `module.json`**, какие события публикует и
   слушает. Это единственная карта связей — держать её честной.
6. **Расчёт нагрузки и любые числа о здоровье считает код, а не ИИ**
   (решение Р-11). ИИ формулирует и выбирает внутри коридора, заданного кодом.
7. **Фото лица и тела не собираем никогда** (решение Р-19): это биометрия,
   которую по закону Узбекистана нужно хранить внутри страны.
8. **В модель уходит обезличенный профиль** — без имени, телефона и Telegram ID.
9. **Обе локали обязательны.** Добавил ключ в `lang/ru.php` — добавь в
   `lang/uz.php` в том же коммите. `/health` показывает непереведённые ключи.
10. **После любой правки — `php tools/smoke.php`.** Красный тест не
    оставляем на потом.

## Команды

```
php tools/smoke.php              все проверки, включая тест отключения модуля
php tools/migrate.php            применить миграции
php tools/migrate.php --dry      показать, что будет применено
php tools/make-module.php Squad  скелет нового модуля
php -S localhost:8000 index.php  локальный запуск, затем /health в браузере
```

## Структура

```
config.php        единственный файл для правки при установке
modules.php       список включённых модулей — главный рычаг управления
index.php         единственная точка входа
app/              ядро: контейнер, модули, события, БД, роутер, контракты
modules/<Name>/   модуль: module.json, Module.php, routes.php,
                  Domain/, Migrations/, lang/
storage/          база, логи, ключ — закрыто от веба
tools/            CLI: миграции, смоук-тест, генератор модулей
```

## Чего не делать

- Не предлагать Laravel, Symfony, Composer, npm — ограничение осознанное.
- Не добавлять функции, которых нет в текущем срезе ROADMAP.md.
- Не расширять продукт за пределы состава тела (решение Р-03): целей
  вида «учёба» и «финансы» в MVP нет.
- Не писать в `README.md` то, чему место в `STATE.md`.
